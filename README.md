## 👋 About Me

I'm a Full Stack Developer with 2+ years of experience building web and mobile applications from the database up to the screen. I work across the whole stack: PostgreSQL models, FastAPI services, and React / React Native interfaces, all running in Docker-based environments.

The problems I enjoy most are the ones where reliability matters: uploads that survive a dropped connection, checkouts that never double-charge, and background sync that keeps working when the app is closed.

- 💼 **Currently:** Full Stack Developer at **IKRGY Infotech Pvt Ltd** (Dec 2025 – Present)
- 📱 **Previously:** Mobile Application Developer at **Maxzen Tech**, Hyderabad (Jun 2024 – Nov 2025)
- 🎓 **Education:** B.Tech in Computer Science, Aditya College of Engineering and Technology (2020 – 2024)
- 📍 **Based in:** Kakinada, Andhra Pradesh, India
- 🧩 **Focus areas:** REST API design, authentication and RBAC, transactional data consistency, mobile background processing

## 🚀 Featured Projects

### 📸 Gallery Hub — Mobile Media Backup App

A mobile app for managing photos and videos, with backup support on Android and iOS.

- Resumable upload pipeline for large videos using 4 MiB chunks, `Content-Range`, SHA-256 verification, status recovery, and retries
- Persistent SQLite upload queue (26 queue fields, WAL, indexing) with network recovery, cancellation, and adaptive 1–8 MiB chunk sizing
- Android foreground backup, background processing, authenticated video playback, and media caching

`React Native` `Python` `FastAPI` `PostgreSQL` `REST APIs` `Android Studio` `Docker`

### 🧾 ERP + POS — Retail ERP and Point of Sale System

A retail platform covering products, inventory, billing, payments, returns, and reporting.

- Transaction-safe checkout using row locking, idempotency, document sequencing, payment validation, and atomic inventory updates
- RBAC, stock movement tracking, returns and refunds, damaged inventory, and audit controls for outlet-level operations
- React.js frontend workflows integrated with backend REST APIs and PostgreSQL data services

`Python` `FastAPI` `React.js` `PostgreSQL` `REST APIs` `Docker`

### 🎓 ICMS — Integrated College Management System

A large-scale college management platform supporting academic and administrative operations.

- Authorization, scope-aware operations, dashboards, and audit-oriented actions across frontend and backend
- Governance workflows for curriculum proposals, course offerings, faculty allocation, timetable changes, academic rollover, and approvals

`Python` `FastAPI` `React.js` `PostgreSQL` `Redis` `Docker`
